# Specification

What Tosi means, in no particular language. Engines implement this; nothing exists only in code.

- `rulebook/`: each step, rule, threshold and data requirement, with its source.
- `schemas/`: what each stage reads and writes, with the precision of every number.
- `cases/`: conformance cases, one folder per stage. Each case is an input and the output every engine must produce.

See [../docs/README.md](../docs/README.md).
